## Verification gate

After every wave:

1. `python3 scripts/audit_coverage.py` — the ABSENT list must shrink and never grow.
2. `python3 /tmp/i09/collide.py` (i09) / the equivalent i08 owner check.
3. `python3 scripts/build_installment.py NN --check-only`
4. build → `import_data.py` → `check_installment.py NN` →
   `validate_database.py --installment NN` → `check_duplicates.py`
5. Re-run the probe; any name still absent must be either written or
   explicitly justified in this file.
